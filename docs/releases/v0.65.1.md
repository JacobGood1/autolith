# Autolith 0.65.1

- Display local Lisp results with width-aware pretty printing, aligned property lists, and syntax colors. Preserve native tool reports, tagged S-expressions, ordinary string notation, and retained async results. Includes Raj's PR #109.
- Export provider usage as JSONL when `ANALYTICS_EVENTS_FILE` is set. Use UTC timestamps, omit unknown token counts, and serialize concurrent appends. Includes sroerick's PR #107 and gregor's corrections.
- Compact large idle histories before estimated prompt-cache expiry. Idle compaction is enabled by default in terminal and ACP sessions.
- Preserve inactive terminal readers across modal input.
- Read the release version from one `VERSION` file for ASDF, runtime reporting, and Nix.

Update with `(update)`.
