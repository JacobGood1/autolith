# Autolith 0.67.7

## Model selection from the shell

- Select a model with `autolith --model MODEL` or `autolith run-job --model MODEL`. Use `--provider PROVIDER` to select a provider explicitly, including custom OpenAI-compatible providers configured in `init.lisp`.
- Override a workspace's saved model for one launch or job without opening the interactive model picker or changing the saved default.

## First-boot input

- At the opening boot screen, press Space or Enter to start onboarding, or press Esc to open the Lisp listener.
- Begin typing or paste a command to open the listener with that text intact. Continue onboarding later with `(onboard)`.
- Read the boot-screen controls on narrow terminals through wrapped instructions.

Update with `(update)`.
