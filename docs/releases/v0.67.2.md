# Autolith 0.67.2

## Prompt caching

- Report cache misses from cached-prefix progression: prefix shrinkage or stagnant cache reads despite accumulated prompt growth. New suffix tokens no longer count as lost reuse.
- Anchor Codex request context per message. Identical context keeps its position across new user messages and tool rounds; one-request contributions use a separate volatile block.
- Preserve complete tool exchanges in their recorded order during resume and cancellation repairs, using clinker-transcript `33f60d6`.
- Add OpenRouter Claude cache-control breakpoints to the system prompt and the end of durable history, before temporary request context.
- Add the same cache-control breakpoints for OpenRouter OpenAI models, using cl-llm-provider-api `7453b6c`.
- Fix the system prompt's date per process. Report a later date separately as request context instead of changing the cached system prompt.

## Source checks

- Run repository coding rules, parinfer-rust indentation checks, Mallet lints, and a clean compile during `./script/check`. Unsilenced compiler warnings, including style warnings, fail the check.
- Use `./script/check --source` for source checks alone, or `./script/check --fix` to apply supported repairs. Build the pinned private parinfer-rust library with `./script/bootstrap`.
- Reformat the source tree and fix coding-rule, lint, and compiler findings. Convert functions with four or more positional parameters to keyword arguments.
- Load matching ASDF/UIOP definitions during Nix startup for the lint dependencies.
- Attribute compiler warnings to exact project components, including translated FASLs, while excluding vendored dependencies.
