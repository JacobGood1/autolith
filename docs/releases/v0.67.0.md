# Autolith 0.67.0

## Memories, knowledge, and procedures

- Record memory sources and premises, show stale or unverified memories during recall, and inspect them with `(memories)` and `(memory "ID")`. Replacing a memory without supplying sources preserves its recorded provenance.
- Store typed facts with units, dates, durations, and evidence. Evaluate admitted rules locally, track conflicting claims, and explain conclusions with `(why "ID")` and `(what-changed)`. Choose active, passive, or off structured-knowledge mode.
- Attach fact requirements to plan steps and missions. Show blocked requirements and flag completed work when its supporting facts stop holding. Expand tasks through checked local methods.
- Check tool calls against admitted action contracts. Use accepted, undisputed facts for requirements and record observations from successful calls through approved mappings.
- Learn reusable procedures from recurring tool sequences in completed turns. Preserve ordinary approvals and contracts, report measured savings with `(procedures)`, and suspend procedures after repeated failures. Running before the model requires admission, exact wording, and demonstrated request and token savings.
- Add optional diagnostic probes to distinguish failure hypotheses before attempting repairs. Inspect cases and their deciding facts with `(diagnoses)`.
- Export and import structured knowledge and procedures together with the memories they depend on.

## Terminal

- Group consecutive single-line tool calls and successful results, display short arguments inline, and show concise failure reasons with a red `!` marker.
- Reduce cache-miss notices, preserve raw diff prefixes, pair typed braces, and highlight REPL work with a fixed status indicator.
- Pin fullscreen activity rows above the composer while the unfinished stream tail scrolls with the transcript.

## Providers and telemetry

- Use models.dev for the provider model catalog, offer the official OpenAI API during onboarding, and use its public Responses API. Preserve provider identity during model selection and stable Codex request prefixes across tool rounds.
- Enable telemetry by default while honoring saved opt-outs. Diagnostic text requires separate consent and local redaction. See `docs/telemetry.org` for the exported fields and controls.

## Platform fixes

- Fix native Windows path handling and sandbox publication races, preserve native-library search paths in supervised workers, and allow Lisp parenthesis checks at approved paths outside the workspace and source roots.

Update with `(update)`.
