# Autolith 0.63.1

## Terminal

- Bracket each fullscreen frame with DEC 2026 synchronized-output controls in Clinedi, using one write and flush. This prevents partial-frame rendering on supporting terminals when a small tty queue splits output.
- Restore synchronized-output mode during remote-session cleanup after an interrupted frame.

## Local sessions

- Flush the `localgroup kill` acknowledgement before shutting down, so a successful kill is reported correctly.

Update with `(update)`.
