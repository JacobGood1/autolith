# Autolith 0.67.5

## Terminal and interaction

- Choose a REPL-style transcript with `>` and `<` markers, and optionally hide the activity line below the modeline. Both settings are available in onboarding choice lessons.
- Show unfinished streamed responses above the modeline without a separate receiving-response activity row.
- End fullscreen message jumps on the bottom transcript row; show the header first for messages taller than the window. Describe legend keys by their purpose.
- Keep Tab from submitting an incomplete form while you are typing it.
- Attach automatic permission decisions to their originating calls, mark standalone notices with a middle dot, and align and style context inspection output.
- Show the cause of a resource-read failure and rail resource-edit delimiter warnings.
- Offer a clickable `job.cancel` call on running handoffs. Accept a job's bare number when it identifies exactly one visible job, including through the public tool schemas.
- Allow periods inside Lisp REPL names.

## Recovery

- Hand detached-session crash capsules to the relaying launcher and run recovery from the relaying terminal.
- Preserve terminal-reader backtraces as frame lists and capture fatal backtraces before their handlers unwind.

## Recursive inference

- Read `rlm.complete` root contexts beyond the editing snapshot limit, using the root-context allowance rather than the smaller frame-view allowance.
- Read complete conversation resources as RLM views, including history beyond the first page.
- Enforce whole-resource limits in UTF-8 bytes, including conversation headers and fallback resource reads.

## Structured knowledge and procedures

- Explain when to use prose memories, facts, rules, task methods, learned procedures, contracts, and diagnosis. Offer this guidance only when the corresponding capabilities are enabled.
- Enable diagnostic probes by default when structured knowledge is active, with the existing setting available to turn them off.
- Offer related learned procedures for differently worded requests so the model can choose a suitable procedure and fill its parameters.
- Read `memory:recipes` for appointment and service-dependency starter vocabularies. Use `recipe-use` to define their predicates and propose their rules; the system prompt points to both recipes and possible procedure fits.
- Install recipe predicates and rule proposals in one transaction, so a conflicting definition leaves no partial recipe. Admit proposed rules only after approval.
- Record contract effects and observations only for successful completed calls, not background handoffs. Keep evidence for calls about different subjects separate even when their results are identical.
- Compare concrete procedure-preflight terms by their values, including equivalent quantities in different units.
- Share the recall allowance between prose memories and facts, retain whole ranked entries, and report only the facts actually delivered.
- Advertise batches of up to 16 operations per `memory:facts` edit without exposing fact-edit guidance in passive or off modes.

## Prompt caching

- Distinguish recovered cache reads from accumulated small losses, including recovery below or at an earlier peak.
- Measure cache stalls against shared request history rather than temporary context or newly offered history.
