# Autolith 0.67.3

## Tool calls

- Click a tool call header in fullscreen to insert its Lisp invocation into the composer for inspection, editing or reuse.
- Preserve the case of local tool argument keys written as escaped keywords such as `:|filePath|` or as strings. Mixed-case JSON parameter names reach the tool unchanged.

## Conversation context

- Prune failed tool exchanges from earlier turns before the first provider request after resume, a provider/model change, or estimated prompt-cache expiry. Remove correlated calls, outputs and reasoning together, including before native or portable compaction. Keep successful exchanges, current-turn failures and the full durable transcript.
- Use the provider's cache-retention estimate or `:prompt-cache-retention-seconds` for idle pruning. Providers without an estimate prune on resume or provider/model changes only.

## Resume performance

- Index outstanding job completions instead of parsing every job continuity file on resume. Large histories, such as a conversation with 6,012 continuity files, no longer require a full scan on each resume.
- Reuse unchanged MCP connections across conversation switches. Resuming a conversation no longer reconnects unchanged servers such as Shodan; retired registries release only connections they exclusively own.

## Reliability

- Retry unexpected TLS EOF failures during provider connection setup, streaming and native compaction through the existing bounded transport retry policy. Certificate errors and unrelated TLS failures are terminal.
- Report the underlying error when a runtime replacement fails.
- Repair recovery builds for existing Linux musl releases by disabling Rust's static CRT default when building parinfer.
- Exclude Mallet, trivial-glob and parinfer from runtime installations, release archives and the Nix package. Install the development dependencies and build parinfer on the first source check.

Update with `(update)`.
