# Autolith 0.65.0

## Corrections and session control

- Use `(complain "...")` or `(wtf "...")` to draft a declarative correction from a complaint. Review or amend it, check it against recent assistant output and tool arguments, then explicitly save it for the workspace or globally.
- Use `(relax t)` to enable a session-scoped system-prompt reminder to complete the requested scope and verification despite unreliable context or token estimates and automatic compaction. Disable it with `(relax nil)`.
- Invoke command aliases directly as Lisp operations.

## Terminal diagrams

- Render Mermaid boxes, edges, arrowheads, and labels with separate theme colors.
- Reduce avoidable crossings with layer ordering, ordered connection ports, and crossing-aware routing.
- Use centered graph layers, compact boxes, rounded connection corners, and Unicode end caps, with ASCII rendering available.

Update with `(update)`.
