# Autolith 0.63.0

## ACP

- Skip empty assistant text chunks. Reasoning fragments interleaved with empty content now appear as one Thought block in agent-shell.
- Cover empty-only output, thought batching before permission requests, and nonstreamed final responses.

## Emacs

- End server requests with a space, matching emacsclient and the current Emacs server protocol.
- Place sly-mrepl across the bottom quarter of the whole IDE frame, with code above-left and agent-shell above-right.

## Runtime and checks

- Recognize the verified SBCL 2.6.9 source archive during bootstrap.
- Shorten the management REPL test socket path and compare resolved GNU tar paths.
- Join task job pools and wait for the test Emacs daemon to exit before deleting their temporary directories; fail cleanup when shutdown times out.
