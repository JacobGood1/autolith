# Autolith 0.67.4

## Prompt caching

- Keep mutable Codex goal and request context after the conversation history, reducing cache-prefix invalidation when agendas, jobs or memories change.
- Persist selected-skill context anchors across resume and project them into cached history on Codex, Anthropic and OpenRouter routes.
- Accumulate small cache-read losses until they reach the reporting threshold.
- Measure precompaction idleness from the latest completed provider response instead of the request start, including after long retries.
- Preserve MCP tool order when a refresh only changes the server's enumeration order.

## Providers

- Request reasoning from all turns on supported Codex models and record the reasoning context mode in request and response diagnostics.
- Count streamed tool arguments and thinking as generated output for retry handling and activity tracking.
- Add `gpt-6.1-terra` to the model picker and use it for the bundled slow and designer roles.

## Terminal status

- Report foreground work, completion, failures and blocked input through the OSC 7501 Program Status Protocol in inline and fullscreen sessions.
- Report child agents and background jobs as independent bounded status records, with conversation and job titles but no assignments or result text.

## Local redaction

- Call `(redact text)` in the user REPL, or `autolith:redact` in Lisp workers and scratchpads, to use the local redaction model. Read the complete redacted string and `:ok`, or `nil` and a failure status. Long prose is processed in bounded pieces; a failed piece rejects the whole result. Review model output before sharing it.

Update with `(update)`.
